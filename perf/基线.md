# 性能基线

基线提交 `c403bd1352b8c946c86e391c7b11200ff5e442a4`。2026-09-27 本机独立 Edge 无头浏览器，1440×900，冷上下文，Fast 4G，全请求限速，CPU 不限速，正式构建；不是线上真实用户数据。

| 操作 / 指标 | p50 | p75 | p95 |
|---|---:|---:|---:|
| 点击晴岚浮岛到可用（10 次） | 6623.6 ms | 6758.4 ms | 7287.3 ms |
| 导航到图鉴点击成功 | 1031.1 ms | 1038.5 ms | 1092.0 ms |
| 主线程长任务总时长 | 1260.5 ms | 1422.5 ms | 2152.4 ms |

原始结果：`bench/base-garden.json`。点击前确认 React 事件已绑定并实际打开图鉴；场景判定为 canvas 存在、加载/错误层消失、跳跃按钮出现。随后真实按移动和两次空格，截图发生变化（这只能作为冒烟，不单独证明所有物理正确）；真实角色和物理正确性由现有 motion/physics/double-jump 测试补充。76 项测试及男女角色动作检查通过。

## 关键路径

- 约 1.99 MB 主角 gzip 与场景 JS 同时下载，已具备按需加载；伙伴在可用后加载，景物分批展开。
- 首轮试跑：模型下载结束约 6.60 s，场景可用 9.18 s，尾部有主线程准备工作。
- 独立代码审计：24,882 个碰撞三角形构建 Octree，暖 p75 约 930 ms；现在放在人物与环境都完成后的 allSettled 中。地形并不依赖人物，应先准备，在模型下载期间重叠执行。
- 该测试服务器的 JS/CSS 没有 HTTP 传输压缩，区别于 CDN；前后保持完全相同，绝对值不能当作线上速度承诺。

## 线上

一次只读检查：geniusqi.com HTTP 200，首字节 0.877 s；同网络 cloudflare.com HTTP 200，首字节 3.881 s。仅连通性样本，不能判定平台快慢。PageSpeed 两个官方 API 入口均返回 HTML 404，本环境未取得 CrUX，不称作「站点没有数据」，也不拿实验室数字冒充真实用户数据。

## 尚未采用的实验

Brotli 无损减小 9%～20%，但当前 Edge 不支持 DecompressionStream('brotli')，不增加浏览器解码依赖。Zopfli gzip 仅减小 1.25%～2.56%（原始见 bench/repack.json），不把小幅字节下降当成已证明的体感收益。骨骼帧优化不解决本轮等待问题。
